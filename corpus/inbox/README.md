# Recording Inbox

This directory is a local staging area for unreviewed recordings. Raw audio is
ignored by Git and must not be committed from here.

Place the first German pilot batch in:

`corpus/inbox/self-recorded/speaker-001/de-DE/pilot-01/`

Use the filenames and script from
`corpus/recording-batches/de-DE-pilot-01.md`. Original WAV, FLAC, M4A, MP3,
OGG, or WebM files are accepted. Keep the recorder's original format and file
extension; do not transcode or denoise recordings before review.
